# Object-Oriented Store

Java 객체지향 설계를 기반으로 상품 등록부터 주문, 결제까지의 온라인-편의점 핵심 흐름을 구현하는 팀 프로젝트입니다.

각 기능의 책임을 도메인별로 분리하고, 회원과 관리자의 역할에 따라 사용할 수 있는 기능을 구분하는 것을 목표로 합니다.

## 프로젝트 목표

- Java 객체지향 프로그래밍을 활용한 쇼핑몰 시스템 구현
- 상품, 행사, 회원, 주문, 결제 도메인의 책임 분리
- Controller, Service, Repository, Model 계층 구조 적용
- 회원과 관리자의 권한에 따른 기능 구분
- ERD를 기반으로 한 데이터 관계 및 PK/FK 설계
- 상품 등록부터 결제와 주문 취소까지의 전체 흐름 구현

## 주요 사용자

### 회원

- 회원가입 및 로그인
- 회원정보 조회·수정·탈퇴
- 상품 전체 조회 및 검색
- 카테고리별 상품 조회
- 진행 중인 행사 조회
- 상품 주문 및 주문내용 수정
- 결제수단 선택 및 결제
- 주문·결제 내역 조회
- 주문 취소
- 회원등급에 따른 포인트 적립

### 관리자

- 상품 등록·조회·검색·수정·삭제
- 카테고리별 상품 관리
- 행사 등록·조회·수정·삭제
- 행사에 적용할 상품 등록
- 회원등급과 포인트 적립률 관리

## 핵심 서비스 흐름

```text
회원가입 및 로그인
        ↓
상품 조회 및 검색
        ↓
카테고리·행사 상품 확인
        ↓
상품 선택 및 주문 생성
        ↓
포인트와 할인금액 적용
        ↓
결제수단 선택 및 결제
        ↓
주문·결제 내역 조회
        ↓
주문 취소 시 포인트 복구
```

## 주요 기능

### 1. 상품 관리

- 판매 상품 등록
- 판매 상품 전체 조회
- 카테고리별 상품 조회
- 상품명 기반 검색
- 상품 정보 수정
- 상품 판매상태 변경

### 2. 행사 관리

- 현재 진행 중인 행사 조회
- 행사 정보 등록
- 기존 상품을 행사에 연결
- 행사 정보 수정
- 행사 종료 및 삭제

행사 하나에 여러 상품을 등록하고, 상품 하나도 여러 행사에 참여할 수 있도록 중간 테이블을 사용합니다.

### 3. 회원 관리

- 회원가입
- 로그인
- 회원정보 조회
- 회원정보 수정
- 회원 탈퇴
- 누적 구매금액에 따른 회원등급 변경
- 회원등급에 따른 포인트 적립
- 관리자 계정 구분

### 4. 주문 관리

- 상품을 선택하여 주문 생성
- 주문 상품 수량 변경
- 결제 전 주문 상품 삭제
- 주문 내역 조회
- 주문 취소
- 주문 취소 시 사용 포인트 복구

### 5. 결제 관리

- 카드 결제
- 카카오페이 결제
- 휴대폰 결제
- 포인트 사용
- 결제 내역 조회
- 결제 취소 처리

## 핵심 도메인

| 도메인 | 역할 |
|---|---|
| Product | 상품 정보와 판매상태 관리 |
| Category | 상품 카테고리 관리 |
| Promotion | 행사 정보와 할인값 관리 |
| PromotionProduct | 행사와 상품의 다대다 관계 관리 |
| Member | 회원 계정과 보유 포인트 관리 |
| MembershipGrade | 회원등급과 포인트 적립률 관리 |
| Order | 주문 총액과 주문 회원 관리 |
| OrderItem | 주문에 포함된 상품과 수량 관리 |
| Payment | 결제수단, 결제상태 및 결제금액 관리 |

## 기술 스택

- Java
- Gradle
- MySQL 8
- JDBC (MySQL Connector/J)
- Git / GitHub
- 관계형 데이터베이스
- ERD 기반 데이터 모델링

## 데이터베이스 연결 설정

1. `database` 폴더의 SQL 파일을 번호 순서대로 실행합니다.
2. `src/main/resources/database.properties.example`을 복사해 같은 위치에 `database.properties`를 만듭니다.
3. 로컬 MySQL의 URL, 사용자명, 비밀번호를 `database.properties`에 입력합니다.

`database.properties`는 로컬 접속 정보를 포함하므로 Git에 커밋되지 않습니다.
